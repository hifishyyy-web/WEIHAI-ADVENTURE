# 威海 WEIHAI ADVENTURE

**2026.09.17(목) ~ 09.21(월) · 4박 5일 · 중국 산둥성 웨이하이 가족여행 앱**

가족 모두가 각자 휴대폰에서 여행 준비물·일자별 동선·필수코스·예산을 함께 확인할 수 있는
설치형 웹앱(PWA)입니다. 링크만 공유하면 되고, 홈 화면에 추가하면 **비행기 안이나 데이터가
안 터지는 곳에서도** 그대로 열립니다.

---

## 담긴 것

| 화면 | 내용 |
|---|---|
| **홈** | 출발 D-day, 우리 항공편(직접 입력), 숙소(기사에게 보여주기), 5일 요약, 9월 날씨, 준비 진행률, 가족 공유 링크 |
| **준비물** | 서류/입국 · 결제 · 통신 · 앱 · 짐 · 출발직전 — 6개 그룹 41개 항목 체크리스트 |
| **일정** | Day 1~5 타임라인. 시간·분류·설명·예상비용, 코스 상세로 바로 이동 |
| **코스** | 필수 코스 10곳(중요도순) + 확정 식당 + 먹거리 8종. 중국어 이름 복사, 高德지도 열기 |
| **예산** | 알뜰/권장/여유 3단계 × 인원수 × 환율 자동 계산 + 여행 중 지출 기록기 |
| **꿀팁** | 현지 생활 팁 12개, 중국어 카드 29개(전체화면 표시), 비상 연락처(터치 시 전화) |

### 이 앱의 특징

- **의존성 0** — 외부 CDN·폰트·라이브러리를 전혀 쓰지 않습니다. 중국 내에서 차단·지연 없이 열립니다.
- **오프라인 동작** — 서비스워커가 앱 전체를 캐시합니다.
- **개인 저장** — 체크리스트·지출·설정은 각자 휴대폰(localStorage)에만 저장됩니다. 서버가 없습니다.
- **설정 공유** — 항공편·환율·인원을 링크에 담아 가족에게 한 번에 전달할 수 있습니다.
- **다크 모드** — 기기 설정을 따르고, 상단 버튼으로 직접 전환도 가능합니다.

## 배포하기

### GitHub Pages (권장 · 무료)

1. 이 저장소의 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정
2. `main` 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 자동 배포합니다
3. 몇 분 뒤 `https://<사용자명>.github.io/WEIHAI-ADVENTURE/` 로 접속

> 이 앱은 빌드 과정이 없는 정적 파일입니다. 저장소 전체가 그대로 배포됩니다.

> ⚠️ **비공개 저장소 주의** — GitHub Pages 는 무료 플랜에서 **공개 저장소만** 지원합니다.
> 저장소를 비공개로 유지하려면 아래의 Netlify / Vercel / Cloudflare Pages 를 쓰세요
> (셋 다 무료 플랜에서 비공개 저장소 배포를 지원합니다).

### 다른 방법

- **Netlify / Vercel / Cloudflare Pages** — 저장소를 연결하고 빌드 명령은 비워둔 채 배포 디렉터리를 `/` 로 지정
- **직접 확인** — `python3 -m http.server 8000` 실행 후 `http://localhost:8000`
  (서비스워커와 ES 모듈 때문에 파일을 더블클릭하는 방식으로는 열리지 않습니다)

## 가족에게 공유하는 법

1. 배포된 주소를 단톡방에 올립니다
2. 각자 링크를 열고 홈 화면에 추가합니다
   - **iPhone**: Safari 하단 `공유` → **홈 화면에 추가**
   - **Android**: Chrome 우측 상단 `⋮` → **홈 화면에 추가**
3. 항공편·숙소를 입력한 사람이 홈 화면 **[링크 공유하기]** 를 누르면
   그 정보가 담긴 링크가 만들어집니다. 그 링크를 공유하면 가족 전원의 앱에 동일하게 반영됩니다.

## 내용 수정하기

여행 정보는 전부 [`assets/data.js`](assets/data.js) 한 파일에 있습니다.

| 상수 | 수정 대상 |
|---|---|
| `TRIP` | 여행 기간, 기본 환율, 날씨 안내 |
| `PREP` | 준비물 체크리스트 |
| `DAYS` | 일자별 타임라인 |
| `STAY` / `RESTAURANTS` | 숙소 · 확정 식당 (비워두면 안내 문구가 대신 표시됨) |
| `SPOTS` / `FOOD` | 필수 코스 · 먹거리 |
| `BUDGET` | 예산 항목과 3단계 금액 |
| `PHRASES` / `TIPS` / `EMERGENCY` | 중국어 카드 · 꿀팁 · 비상 연락처 |

수정 후 푸시하면 자동으로 재배포됩니다. 캐시 때문에 예전 화면이 보이면
`sw.js` 첫 줄의 `VERSION` 값을 올려주세요 (`weihai-v1` → `weihai-v2`).

아이콘을 다시 만들려면 `node scripts/gen-icons.mjs` (외부 패키지 불필요).
